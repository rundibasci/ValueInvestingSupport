# RD2-1 Screenshot Checklist

Store screenshots in this folder using the filenames below. Redact tokens, email addresses beyond test accounts, and any local secrets if browser developer tools are visible.

| Filename | Persona | Route or Surface | Required Evidence |
|---|---|---|---|
| `01-universe-template-preview.png` | Investor | `/universe-curation` | Defensive-quality template selected, preview count visible, criteria visible. |
| `02-curated-universe-seeded.png` | Investor | `/universe-curation` | Seed result or queued ingestion confirmation for the curated universe. |
| `03-ingestion-monitoring.png` | Admin | Job control panel | Per-symbol ingestion progress or events for curated symbols. |
| `04-conservative-screener.png` | Investor | `/screener` | Conservative preset or equivalent filters with ranked curated results. |
| `05-review-top-candidate.png` | Investor | `/securities/{symbol}/review` | Valuation, FCF, earnings, debt, dividends, charts, and data-quality labels. |
| `06-comparison-top-five.png` | Investor | Comparison workflow | Top 5 candidates compared on MoS, score, quality, risk, dividend, and coverage. |
| `07-defensive-portfolio.png` | Investor | `/portfolio` | 5 to 8 stock defensive portfolio with concentration evidence. |
| `08-watchlist-rationale.png` | Investor | `/watchlist` | 3 to 5 almost-cheap-enough symbols with rationale notes. |
| `09-dashboard-alerts.png` | Investor | Dashboard | Portfolio/watchlist summary and configured alert evidence. |

Screenshots are stakeholder evidence only and must not imply a recommendation to buy or sell any security.
